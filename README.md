# Чат MAX

Веб-чат для текстовых сообщений в мессенджере MAX через [GREEN-API](https://green-api.com/max).

## Запуск

```bash
npm install
npm run dev
```

Откройте адрес, который покажет Vite. В режиме разработки запросы к GREEN-API идут через прокси Vite, чтобы браузер их не блокировал. На экране входа укажите `idInstance` и `apiTokenInstance` из личного кабинета GREEN-API.

Инстанс должен быть авторизован в MAX. После входа приложение включает получение уведомлений по HTTP API: очищает `webhookUrl` и включает входящие и исходящие уведомления.

## Как пользоваться

1. Войдите с данными инстанса.
2. Введите номер телефона получателя (Россия или Беларусь) и создайте чат.
3. Отправьте текстовое сообщение.
4. Ответ из MAX появится в этом же диалоге.
